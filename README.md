## 🔍 主要发现

**年度趋势**: 2022年因留抵退税集中曝光达到峰值（623条），2025年起强力反弹。

**案件类型**: 骗享优惠（含留抵退税）占60%，虚开发票10.3%，网络主播5.1%。

**最新趋势（2026年）**: 私户收款专项整治、高收入自然人个人所得税专项、医疗美容行业曝光。
